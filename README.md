## 📅 Sistema de Agenda - Flask
## 📖 Descrição
O <strong>Sistema de Agenda</strong> é uma aplicação desenvolvida em Flask que permite o cadastro de clientes, agendamento de consultas por data e hora, painel administrativo e envio de confirmações.
O projeto foi criado com foco em simplicidade, eficiência e usabilidade, sendo ideal para pequenas empresas, clínicas ou profissionais autônomos que precisam organizar seus atendimentos.
<strong>Saiba mais:</strong> https://agenda-5p0a.onrender.com/login
## ✨ Funcionalidades

- Cadastro de clientes com informações básicas.

- Agendamento de consultas por data e hora.

- Painel administrativo para gerenciar clientes e agendamentos.

- Envio de confirmações por e-mail (opcional).

- Layout responsivo com Bootstrap.

- Banco de dados SQLite simples e eficiente.

## 🛠 Tecnologias Utilizadas

- Python 3.x

- Flask (framework backend)

- SQLite (banco de dados)

- WTForms (formulários)

- Bootstrap 5 (frontend responsivo)

- Flask-Mail (envio de e-mails, se configurado)
